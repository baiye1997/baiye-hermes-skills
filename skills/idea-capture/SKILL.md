# 灵感捕捉

快速记录闪现的想法、灵感、待办，自动写入 Obsidian 并关联相关笔记。

## 使用场景

- "我突然想到一个点子..."
- "帮我记一下..."
- "这个值得记下来..."

## 执行流程

1. **接收想法**：用户口述或简短描述
2. **智能分类**：判断属于哪个领域（投资/技术/生活/读书/其他）
3. **生成笔记**：
   - 标题：提炼核心关键词
   - 正文：用户原始描述 + 延伸思考
   - 标签：自动打标签
   - 关联：搜索 vault 中相关笔记，添加 wiki-link
4. **写入 Obsidian**

## 输出格式

```markdown
---
date: {YYYY-MM-DD HH:mm}
type: 灵感
tags:
  - {自动标签}
related: [{关联笔记 wiki-link}]
---

# 💡 {标题}

> {一句话概括}

---

## 原始想法

{用户原始描述}

---

## 延伸思考

- {延伸思考1}
- {延伸思考2}
- {可能的行动项}

---

## 相关笔记

- [[{相关笔记1}]]
- [[{相关笔记2}]]

---

*💡 捕捉于 {时间}*
```

## 文件存储

```
~/obsidian-vault/💡 灵感捕捉/{YYYY-MM-DD}-{标题关键词}.md
```

## 注意事项

- 笔记要简短精炼，不要写成长文
- 关联笔记最多 5 条，避免过度关联
- 处理完成后执行 `cd ~/obsidian-vault && ob sync`
