# 知识图谱分析

分析 Obsidian vault 中笔记的关联关系，发现知识盲区和关联模式。

## 功能

1. **关联分析**：找出笔记之间的 wiki-link 关系
2. **孤岛检测**：发现没有关联的孤立笔记
3. **热点发现**：识别高频出现的关键词/主题
4. **图谱可视化**：生成 Mermaid 图谱展示关联

## 执行流程

1. **扫描 vault**：读取所有 .md 文件的 frontmatter 和 wiki-link
2. **构建关系图**：笔记 → 关联笔记 的有向图
3. **分析统计**：
   - 每篇笔记的关联数
   - 高频关键词 TOP10
   - 孤立笔记列表
   - 最强关联对
4. **生成报告**：写入 Obsidian
