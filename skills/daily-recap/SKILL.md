# 每日对话回顾

每天晚上自动总结今天与用户的对话，生成个人日记。

## 功能

- 记录今天做了什么任务
- 记录做了什么决策
- 记录有趣的对话瞬间
- 记录待办和明日计划

## 执行流程

1. **获取今日对话**：通过 session_search 搜索今天的会话记录
2. **提取关键信息**：
   - 完成的任务
   - 做出的决策
   - 有趣的对话/金句
   - 未完成的待办
3. **生成日记**：按模板组装，文件名加精炼标题
4. **写入 Obsidian**：`write_file` 到 vault 路径
5. **同步**：执行 `cd ~/obsidian-vault && ob sync`
6. **更新索引**：更新 `~/obsidian-vault/README.md`（二掌柜的酒铺篇数）和 `graph.md`
7. **发送摘要**：Telegram 推送 3-5 句话概括今天

## 输出格式

```markdown
---
date: {YYYY-MM-DD}
type: 日记
tags:
  - {自动标签1}
  - {自动标签2}
---

# 📝 {YYYY}年{M}月{D}日 · {星期X}

---

## ✅ 今日完成

- {任务1}：{简要描述}
- {任务2}：{简要描述}
- ...

## 🎯 做出的决策

- {决策1}：{为什么这样选择}
- {决策2}：{为什么这样选择}

## 💬 今日趣事

> {有趣的对话片段或金句}

## 📌 待办/明日

- {未完成的事}
- {明天计划}

## 💡 今日收获

> {学到了什么/发现了什么}

---

*📝 由 Hermes 自动生成*
```

## 文件存储

```
~/obsidian-vault/🍺 二掌柜的酒铺/{YYYY}/{MM}/{YYYY-MM-DD}-回顾-{精炼标题}.md
```

按年月分文件夹，例如：`🍺 二掌柜的酒铺/2026/04/2026-04-24-回顾-Skill大整理与博客暗黑模式上线.md`

**文件名规则**：`{YYYY-MM-DD}-回顾-{精炼标题}.md`，"回顾"前缀与其他笔记区分。从当日内容提炼 1-2 个核心事件，凝练成简短标题（10-20字）。

## 定时任务

每天晚上 23:00 自动生成

```
schedule: "0 23 * * *"
```

## graph.md 更新规则

`graph.md` 按笔记分类维护关联图谱。添加日记时：
1. 如果该分类（如 `🍺 二掌柜的酒铺`）已有对应区块，在其下追加新条目
2. 如果是新分类，在 `## 🔗 跨领域关联` 之前插入新区块，格式：`## {emoji} {分类名} → 相关笔记`
3. 更新底部 `## 📊 统计` 中的篇数和总计

## 注意事项

- 如果今天没有对话，跳过不生成
- 内容要精炼，不要流水账
- 保护隐私，不记录敏感信息
- cron 模式下无需调用 send_message，最终回复会自动投递
- 处理完成后执行 `cd ~/obsidian-vault && ob sync`
