# Obsidian 智能标签系统

自动为 Obsidian vault 中的笔记提取关键词并添加标签。

## 使用场景

- 新笔记生成后（如山水邸报）自动打标签
- 批量扫描历史笔记，补充标签
- 定期更新标签（内容变化后重新提取）

## 标签提取规则

### 1. 预定义标签词库（按领域）

**投资/财经：**
```
基金, 股票, A股, 港股, 美股, 债券, 黄金, ETF, 指数基金,
上证, 深证, 创业板, 恒生, 纳斯达克,
央行, 降准, 降息, CPI, GDP, PMI,
白酒, 半导体, 新能源, 医药, 军工, 银行, 地产
```

**科技/AI：**
```
AI, 大模型, GPT, Claude, Gemini, Agent, Sora,
芯片, 机器人, 自动驾驶, 具身智能,
小米, 华为, 苹果, 特斯拉, 英伟达
```

**政策/时政：**
```
碳中和, 双碳, 节能降碳, 新能源,
中美, 关税, 贸易战, 制裁,
央行, 国务院, 发改委
```

**生活/文化：**
```
{城市}, 天气, 穿衣, 出行,
历史, 人文, 科技, 数码
```

### 2. 动态关键词提取

对于词库未覆盖的内容，从笔记正文中提取：
- 出现频率 ≥ 3 次的名词短语
- 标题中的核心词
- 正文中加粗/高亮的内容

### 3. 标签数量控制

- 每篇笔记 3-8 个标签
- 优先使用预定义标签（标准化）
- 动态标签作为补充（灵活性）

## 执行流程

### 单篇笔记处理

1. 读取笔记内容（frontmatter + body）
2. 提取已有 tags
3. 根据规则生成新 tags
4. 合并去重（保留已有 + 新增）
5. 更新 frontmatter

### 批量扫描

```bash
# 扫描整个 vault
find ~/obsidian-vault -name "*.md" -not -name "README.md" | head -50
```

对每篇笔记执行单篇处理，跳过已有完整标签的笔记。

## 标签更新格式

修改 frontmatter 的 tags 字段：

```yaml
---
date: 2026-04-23 星期四
type: 早报
weather: 周边有零星小雨 16°C - 26°C
tags:
  - 山水邸报
  - 碳中和
  - 半导体
  - 央行降准
  - A股
---
```

## 注意事项

- **不删除已有标签**：只新增，不移除用户手动添加的标签
- **保留原有格式**：frontmatter 的其他字段不变
- **同步**：处理完成后执行 `cd ~/obsidian-vault && ob sync`
- **批量处理时**：每处理 10 篇暂停确认，避免误操作
