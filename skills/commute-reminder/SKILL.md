## 数据来源

### 天气
```bash
curl -s "wttr.in/{CITY}?format=j1&lang=zh"
```

### 路况
使用高德地图 API（amap-lbs-skill）：
- 驾车路线规划
- 实时路况查询
- 预计用时

### 今日事项
从当天山水邸报早报中提取关键事项。

## 定时任务

### 早间推送
```
schedule: "0 8 * * 1-5"
```

### 晚间推送
```
schedule: "30 17 * * 1-5"
```

## 推送方式

发送到 Telegram（当前对话）

## 注意事项

- 只在工作日推送（周一到周五）
- 路况数据可能有延迟，仅供参考
- 搬家后记得更新起点地址
- 限行信息需要额外数据源，初期可跳过
